## 보안

현재 확인된 치명적 보안 실패는 없다. 과거 Git 이력의 리터럴 값은
운영 자격 증명으로 재사용하지 않으며, 원격 공유 전에 현재 트리 비밀값
검사를 다시 수행한다.

## 비용

무료 플랜 적용 여부와 잔여 크레딧은 계정별로 다르다. 서울 리전
`t3.small`, 공개 IPv4, gp3 비용을 결제 화면과 비용 탐색기에서 확인하고,
예산 실제 알림 12 USD와 월 최대 15 USD를 넘기기 전에 인스턴스를
중지한다. 중지 중에도 EBS와 공개 IPv4 관련 비용은 별도로 확인한다.
